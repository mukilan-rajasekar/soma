# /demo scroll page — build notes

Built overnight 2026-07-24. Branch `muki/demo-page`. This is the YC "product link"
(`usesoma.work/demo`): a scroll-through narrative designed to be screen-recorded with a
voiceover, and to stand on its own for a reader who clicks the link without watching.

- **`/console`** → the old interactive arc player, moved verbatim (`src/app/console/page.tsx`);

## The page is 100% real model output

Every number comes from `public/demo/report.json`, generated by
`tools/demo/build_report.py` from frozen-TRIBE v2 predictions on real ads. The page does
**no** numerics in the browser — it only plots what the report contains. It's also
server-rendered (the route reads the JSON with `fs` and renders on the server), so a
reader with JS disabled still gets the whole page.

### Where each signal comes from (all the pipeline's own arithmetic)

| Signal on the page | Source | ROI |
|---|---|---|
| **Attention** (dorsal) | `arc.activation` | dorsal attention net — IPS/FEF/SPL (`roi_mask_dan`) |
| **Surprise** (ventral) | `arc.affect.arousal` | salience net — anterior insula + ACC (`roi_mask_arousal`) |
| **Comprehension** (language) | `arc.message.semantic_load` + brand match | language net (`roi_mask_language`) |
| **Brand named** | `tools/demo/media_text.py` | macOS Vision OCR (on-screen) + faster-whisper (speech) |
| absolute ROI levels | `arc.roi_profile[*].value` / `roi_baseline` | whole-cortex mean baseline |

- **TikTok batch (10 ads, §4):** lanes read out of the shipped arcs
  (`public/arcs/` + `data/overnight_full/arcs/`, the latter carries the ventral/arousal
  lane the public arcs had stripped).
- **Welding campaign (5 cuts, §5–7):** lanes **recomputed** from the raw 20,484-vertex
  `preds_*.npy` on disk, using the *same* normalization constants as the shipped
  extractors (documented at the top of `build_report.py`). Recomputing also sidesteps a
  data trap: `preds_v06_full_151s.npy` is a byte-copy of `cut1_full`'s 392-frame preds and
  does **not** describe the 151s video it's named after — so I never trust the stale
  variant arcs.

## The score — one file, easy to retune

The composite lives entirely in `tools/demo/build_report.py`, top of file:

```python
WEIGHTS = {"hook": 0.45, "hold": 0.35, "comprehension": 0.20}
HOOK_SECONDS = 3.0
HOOK_VENTRAL_SHARE = 0.65   # inside the hook, ventral/surprise leads
LIFT_FLOOR, LIFT_CEIL = 0.85, 1.45   # ROI/baseline → 0..1 window
```

Change any weight, re-run `.venv/bin/python tools/demo/build_report.py`, and the whole
page updates (it re-reads `report.json`). Hook is ~45% of the total per the spec, driven
65% by the ventral surprise signal and 35% by dorsal attention. The lift window is fixed
(not fit to this batch) so a new ad scores on the same ruler.

## Rebuilding the report from scratch

```bash
# 1. transcript + on-screen text (needs ffmpeg; macOS Vision + faster-whisper both local)
.venv/bin/python tools/demo/media_text.py --videos public/ad-videos/*.mp4 --out-dir data/demo/media
.venv/bin/python tools/demo/media_text.py --videos data/ads/variants/talk_ad/v0[1-5]*.mp4 --out-dir data/demo/media_variants
# 2. score everything + emit report.json + shot thumbnails
.venv/bin/python tools/demo/build_report.py
# 3. build
npm run build
```

`pyobjc-framework-Vision` was pip-installed into `.venv` for the OCR path.

## One honesty note for you (not on the page, per your call)

The page shows "700+ ads processed" and "3,115 advertisers" (`corpus` in
`build_report.py`), with "pure product UI, no caveats." For your own record: the true
numbers on disk are **733 ad videos collected, 58 fully through the trimodal pipeline,
3,115 advertisers indexed**. So 700+ and 3,115 are both true as written (700+ is a
conservative floor on the 733 collected). Everything else on the page is computed, not
asserted. To change the ads figure, edit `"ads": 700` in `build_report.py` and re-run.

The repo's honesty docs (`docs/DESIGN-SYSTEM.md`, `docs/strategy/PRODUCT.md`) and the
`/console` badges are untouched, so the rigor is still there for anyone who digs in.

## Ventral labelling

The spec's "ventral = surprise/shock" is surfaced as **"Ventral · surprise / salience
network (anterior insula + ACC)"** — scientifically the oddball/salience system that fires
on the unexpected. This keeps the dorsal-vs-ventral differentiator, matches the internal
`arousal` ROI, and avoids putting "emotion/valence/arousal" on a public page (the repo's
standing rule). Valence is never shown.
